How a flattened answer can land on a branch with no knowledge

In 30 seconds: imagine an AI stores what it knows as a branching tree, from broad topics at the top to single facts at the bottom. To speak, it must squeeze that tree onto one line of numbers and keep only the first few digits. Facts that share those digits become one blurry spot. If that spot sits on a branch where the AI knows nothing, the answer is a hallucination. Pick a fact below, then reduce the digits kept.

What the paper defines (and this demo uses)

Knowledge is a p-ary tree of depth D (here p=2, D=5). A leaf's path is x = Σ ai p-i. The Monna map reads that expansion as a real number φ(x) = Σ ai p-i in [0,1]. Keeping only the top k digits maps every leaf under the same branch to one value (many-to-one).

Numbers the paper states

D=5, k=2: survival fraction
L=20, k=10: distinguishable fraction
Geometric depth, q=0.7 (assumed), k=10, L=20: unrecoverable floor
D=5, k from 2 to 4: loss 0.6 to 0.2

These are computed live by the same code that the tests check against the paper.

What this does not show

  • It does not show that real language models work this way. The paper itself says no implementation has been demonstrated and its core claim is untested.
  • Which leaves count as "known" is random, chosen for illustration. Real knowledge is not a neat binary tree.
  • Real hallucinations also come from other sources (data noise, language priors, decoding) that the paper sets aside.
  • Reading a truncated answer as "the first leaf under that branch" is this demo's simplification, so which answers count as hallucinations is a toy choice.
